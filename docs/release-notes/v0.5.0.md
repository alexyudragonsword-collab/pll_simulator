pllsim v0.5.0 — native desktop GUI (PySide6)

Highlights since v0.4.0:

- PySide6 desktop application (English UI) alongside the Streamlit web
  GUI: pip install -e .[guiqt]; launch with `pllsim-gui` (console
  script) or `python -m pllsim.guiqt`
- Same eleven pages as the web flavor: architecture workbench
  (auto-generated forms for every Config field from the shared
  pllsim.guiutil introspection -> analyze()/simulate() with the full
  plot set), loop synthesis, architecture selector, spur prediction,
  measured-PN fitting (file dialog or synthetic demo), two-point GMSK
  modulation, hop settling with the live FLL-stability check, drift
  tracking, Monte Carlo yield, VAMS export to a chosen folder,
  benchmark table
- All computation on QThread workers (UI stays responsive); matplotlib
  canvases embedded via QtAgg; single-flight run guards per page
- Offscreen smoke tests (QT_QPA_PLATFORM=offscreen) exercise the main
  window, all eleven pages, the workbench compute/render path and the
  form-override flow; auto-skipped where PySide6 or system GL libraries
  are absent; CI installs the [guiqt] extra + libegl
- Suite at 155 tests
