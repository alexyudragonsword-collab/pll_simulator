pllsim v0.5.1 — Windows onefile executables for both GUIs

Highlights since v0.5.0:

- windows-exe GitHub Actions workflow (workflow_dispatch): builds
  ONEFILE Windows executables for both GUIs with PyInstaller on
  windows-latest and smoke-tests them on the runner before upload -
  the desktop exe must open, render and exit clean (PLLSIM_SMOKE
  hook), the web exe must serve HTTP 200
- pllsim-gui-qt.exe: PySide6 desktop workbench, windowed (no console)
- pllsim-gui-web.exe: bundles streamlit + the gui/ pages as data,
  starts the local server and auto-opens the default browser; the
  console window is the server log (PLLSIM_PORT / PLLSIM_NO_BROWSER
  env overrides)
- Both exes upload as run artifacts; optionally attach to an existing
  release by passing its tag as the workflow input
- packaging/launch_qt.py and launch_web.py double as local launchers
  (verified: web serves 200, desktop smoke exits 0)
