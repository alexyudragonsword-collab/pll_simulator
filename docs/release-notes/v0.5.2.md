pllsim v0.5.2 — Nuitka Windows executables alongside PyInstaller

Highlights since v0.5.1:

- windows-exe-nuitka GitHub Actions workflow (workflow_dispatch):
  compiles both GUIs to ONEFILE Windows executables with Nuitka
  (real C compilation via MSVC - slower builds, faster startup than
  PyInstaller's self-extract), as an alternative to the PyInstaller
  workflow
- pllsim-gui-qt-nuitka.exe: PySide6 plugin enabled, windowed
- pllsim-gui-web-nuitka.exe: streamlit compiled in with its package
  data and distribution metadata, gui/ pages as data files
- qt and web build as INDEPENDENT jobs, so a Streamlit freezing issue
  never blocks the desktop exe (and vice versa); Nuitka's compile
  cache is persisted across runs via actions/cache
- Same gate as the PyInstaller flow: every exe is smoke-tested on the
  runner before upload (desktop opens/renders/exits clean via
  PLLSIM_SMOKE; web must serve HTTP 200); artifacts per run, optional
  release-asset upload via the release_tag input
